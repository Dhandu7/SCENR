- **Contributor web** (`apps/contributor-web`, Next.js, scaffolded from scratch) — `/join/[slug]` page: resolves a trip, uploads a file via the three-function chain, confirms.

## Assumptions / gaps (accepted, not fixed)

Explicit decisions, most already scoped out in `docs/plan.md`'s Global Constraints, reconfirmed here for the record:

- **TOCTOU race on the 50-upload-per-trip cap** (count-then-insert, not atomic). Accepted as a soft product quota, not a security boundary — revisit when real billing/quotas are built later in the project.
- **No drag-and-drop upload** (tap-to-choose only), **no contributor display-name capture**, **no pixel-perfect Figma styling** — deliberate scope trims for this slice; polish is Days 10-12 per `docs/plan.md`.
- **Contributor-web runs on `localhost:3000` only** — no real deployment yet. The invite QR's URL won't resolve from a separate physical phone until either a LAN IP or a real deploy exists (Days 13-14 per `docs/plan.md`).
- **Upload size/content-type checks are advisory only** — declared `file_size`/`content_type` aren't verified against the actual bytes sent to the signed URL. Consistent with the "soft quota" decision above.
- **Apify/Anthropic/Voyage API keys still not provided** — the theme-loader workstream (W5) hasn't started; nothing built today needed them.
- **`packages/shared-types` isn't wired into the apps or edge functions yet** — needs workspace/import-map setup, deferred (noted in the `/simplify` commit).
- **A shared mobile theme/style module doesn't exist yet** — colors like `#1D4ED8` are inlined per-screen. Deferred; button styles have real per-screen variants and visual theming is a Days 10-12 concern anyway.
- **Test data live in the database**: three test trips (Bali 2026, Stampede 2026, Toronto 2026) and one test `media_items` row from today's verification. Cosmetic only, but worth a clean slate before any real demo.
